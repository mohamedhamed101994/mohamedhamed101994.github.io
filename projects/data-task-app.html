Data Task App

A data-request management system for a data team, built on Microsoft 365 and Power BI tools the organization already licensed — no new systems or budget.

Business problem

Requests to the data team arrived through Teams, email and in person. There was no single view of who was working on what, which requests were delayed, or how workload was distributed.

Solution

Microsoft Forms→SharePoint Lists→Power Automate→Power Apps→Power BI
  • Microsoft Forms: structured request intake.
  • SharePoint Lists: the central data store.
  • Power Automate: workflow and notifications.
  • Power Apps: analyst workspace where each analyst sees only their assigned tasks.
  • Power BI: management view of SLA, status and workload KPIs.

Features

  • Automated workflow and notifications
  • SLA monitoring and status tracking
  • Analyst comments on each request
  • Workload distribution across the team
  • Interactive management dashboards
