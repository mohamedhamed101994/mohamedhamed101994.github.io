Reporting Automation

A Python pipeline that checks incoming CSV report files before they reach SQL Server — so bad data never reaches the database or the Power BI reports built on it.

Business problem

Manual checks on incoming report files let bad data slip through to the database and to downstream reports.

Workflow

Incoming CSV files→Validation→SQL Server staging→Power BI

Files that fail validation go to a Rejected folder with an error log instead.

Approach

  • Scan an incoming folder and check each new CSV file.
  • Validate required columns, missing values, numeric scores within 0–100, valid dates and duplicate records.
  • Load valid files into a SQL Server staging table with SQLAlchemy (fast_executemany), then move them to a Processed folder.
  • Move invalid files to a Rejected folder with an error log that explains each failure.
  • Keep connection settings in an environment file, not in the code.
